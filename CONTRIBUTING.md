# Contributing

Thank you for your interest in contributing to this repository.

This repository explores architectural patterns for building AI agents with Koog. Contributions that improve clarity, technical accuracy, documentation quality, or practical engineering guidance are welcome.

---

# Ways to Contribute

Examples include:

- Improving architecture documentation
- Suggesting new blueprint ideas
- Correcting technical inaccuracies
- Improving diagrams
- Expanding evaluation guidance
- Improving threat modelling guidance
- Sharing reference implementations or engineering examples
- Fixing documentation issues

---

# Contribution Principles

Please aim to:

- Keep discussions constructive and respectful.
- Prefer clear architectural reasoning over unnecessary complexity.
- Clearly distinguish implemented functionality from architectural proposals.
- Avoid unsupported technical claims.
- Keep documentation concise and technically accurate.

---

# Before Opening a Pull Request

Consider whether your contribution:

- Improves architectural understanding
- Aligns with the repository's scope
- Maintains consistency with existing documentation
- Includes appropriate references where helpful

---

# Discussions

Questions, suggestions, and architecture discussions are encouraged through GitHub Issues and Pull Requests.

Constructive feedback, thoughtful discussion, and collaborative improvements are always appreciated.

---

# Code of Conduct

Please help maintain a welcoming, respectful, and collaborative environment for everyone contributing to the project.
