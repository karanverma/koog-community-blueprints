# Edge Agent

## Overview

This document explores a local-first AI agent architecture built around Kotlin Multiplatform, Koog 1.0, and LiteRT.

The goal is to investigate how agent workflows can run closer to users while prioritizing privacy, offline functionality, and reduced network dependency.

## Areas of Interest

* Kotlin Multiplatform
* LiteRT integrations
* On-device inference
* Privacy-focused workflows
* Offline execution scenarios

## Status

Exploration and design phase.
